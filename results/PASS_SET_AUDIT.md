# Auditing the pass set

Generated by `tests/audit/pass_set_audit.py` from committed artifacts. No number below is hand-typed.

**The question.** A false dataset statement damages the measurement in two directions. It either cannot be closed — the model fails and we log `compile_error`, scoring the dataset's error against the prover — or it makes the hypotheses mutually inconsistent, in which case `False` follows, every goal follows, a proof compiles, and we log a **pass**. The first direction was measured. The second was not, and it is the one that flatters us.

**Vacuity is decided by hypothesis consistency, never by tactic name.** Two methods with different failure modes are run over the same passes: a Lean probe for `False` from the hypotheses alone, and an exact-arithmetic static evaluation that substitutes bindings before checking. Neither is authoritative alone; their agreement is the evidence.

### Corrected pass rates

| what is being counted | rate | 95% Wilson |
|---|---|---|
| compile rate — a proof of the target compiled | **37/50 = 74%** | [60%–84%] |
| minus vacuous passes (hypotheses inconsistent) | **36/50 = 72%** | [58%–83%] |

**Removing vacuous passes moves 74% to 72% — one sample.** The larger correction is not vacuity but triviality: 14 of 37 passes assert nothing at all.


### The vacuous pass — sample 42

```
hypothesis `9! * 5! * 2! = 7257600` is FALSE: 87091200 vs 7257600
```

Every hypothesis is arithmetically false and they are mutually inconsistent, so `False` follows and therefore every goal does. The proof compiles, proves the stated goal, and stands on no untrusted axiom — every existing check passes. See issue #13.

## How much of the benchmark asserts false things

The sampled 50 are not the benchmark. `tests/audit/statement_truth_scan.py` evaluates the closed arithmetic of every one of the **30,809 statements** across all **500 problems**.


18,557 of 30,809 rows (60%) have at least one claim that evaluates to a closed value. That is the only honest denominator: a row whose claims never close is not evidence either way and leaves both sides.


| | n | share of checkable |
|---|---|---|
| statement asserts something **false** | 1,567/18,557 | **8%** [8%–9%] |
| …of which a **false hypothesis** — the vacuity-producing class | 215/18,557 | **1%** [1%–1%] |
| …of which only a **false goal** — simply unprovable | 1,352/18,557 | **7%** [7%–8%] |

**Per problem: 303 of 500 problems contain at least one arithmetically false step — 61%** [56%–65%].


The false-hypothesis class is the one that can manufacture a pass. It is the smaller share, which is consistent with finding exactly one vacuous pass in the sampled 50 — but it is not zero, and it scales with the eval set.


**Scope.** This finds statements whose *closed arithmetic* is false. It cannot see a statement false for a non-arithmetic reason, and it says nothing about the 40% of rows whose claims never close. Every number above is a lower bound on how much of FormalStep is wrong.
