# What the failures actually are

Generated by `classify_results.py` from committed artifacts. No number
below is hand-typed. Categories were derived from the observed Lean
output across both runs (issue #14), not invented ahead of the data.

**Two axes.** `failure_kind` reads the compiler's own words.
`arithmetic` answers a different question -- was a NUMBER wrong, and
whose -- and is joined from `results/arithmetic_provenance.json`, which
substitutes hypotheses before evaluating. It is not re-derived from
error text, because no regex over error text could do it.

`statement_arithmetic` means the DATASET's number is wrong;
`proof_arithmetic` means a number the MODEL wrote is wrong.
